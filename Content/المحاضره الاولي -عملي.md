# المحاضرة الأولى - عملي (Lecture 1 – Practical)

## QUREO – First Four Chapters

---

## Chapter 1: Introduction to Programming

### Topics
- What is Programming?
- Programming Languages
- How to Use the Code Editor
- Console
- Comments

### Practical Examples

Printing text:

```javascript
console.log("Hello");
console.log("Good morning");
```

Writing comments:

```javascript
// This is a comment
console.log("Hello World");
```

---

## Chapter 2: Calculations and Strings

### Topics
- Arithmetic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Working with Strings
- Displaying Calculation Results

### Practical Examples

Arithmetic operations:

```javascript
console.log(10 + 5);
console.log(10 - 5);
console.log(10 * 5);
console.log(10 / 5);
```

Working with strings:

```javascript
console.log("Hello" + " World");
console.log("My age is " + 16);
```

---

## Chapter 3: Variables

### Topics
- What is a Variable?
- Declaring Variables
- Assigning Values
- Changing Variable Values
- Using Variables in Calculations
- Displaying Variables

### Practical Examples

Declaring variables:

```javascript
let age = 16;
let score = 100;

console.log(age);
console.log(score);
```

Changing variable values:

```javascript
let number = 10;

number = 20;

console.log(number);
```

Using variables in calculations:

```javascript
let x = 10;
let y = 5;

console.log(x + y);
```

## Chapter 4: Review and Midway Test

### Topics
- Review of Chapter 1
- Review of Chapter 2
- Review of Chapter 3
- Writing and Running Code
- Practical Exercises
- Midway Test

### Review Exercises

1. Print "Hello World" using console.log().
2. Print the result of 15 + 20.
3. Print the result of 50 - 10.
4. Join two strings together.
5. Create a variable called `name` and assign a value to it.
6. Create two variables and print their sum.
7. Change a variable's value and print the new value.

---

## Suggested Teaching Sequence

1. Introduction to Programming
2. Console and Comments
3. Arithmetic Operations
4. Strings
5. Variables
6. Assignments and Calculations
7. Review and Practical Exam

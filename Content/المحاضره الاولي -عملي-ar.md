## الفصل الأول: مقدمة في البرمجة

### الموضوعات
- ما هي البرمجة؟
- لغات البرمجة
- كيفية استخدام محرر الأكواد (Code Editor)
- الكونسول (Console)
- التعليقات (Comments)

### الأمثلة العملية

طباعة نص على الشاشة:

```javascript
console.log("Hello");
console.log("Good morning");
```

كتابة التعليقات:

```javascript
// هذا تعليق — الكمبيوتر مش بينفذه
console.log("Hello World");
```

## الفصل الثاني: العمليات الحسابية والسلاسل النصية

### الموضوعات
- العمليات الحسابية
- الجمع (+)
- الطرح (-)
- الضرب (*)
- القسمة (/)
- التعامل مع السلاسل النصية (Strings)
- عرض نتائج الحسابات

### الأمثلة العملية

العمليات الحسابية:

```javascript
console.log(10 + 5);
console.log(10 - 5);
console.log(10 * 5);
console.log(10 / 5);
```

التعامل مع السلاسل النصية:

```javascript
console.log("Hello" + " World");
console.log("My age is " + 16);
```

## الفصل الثالث: المتغيرات

### الموضوعات
- ما هو المتغير؟
- الإعلان عن المتغيرات (Declaring Variables)
- تعيين القيم (Assigning Values)
- تغيير قيم المتغيرات
- استخدام المتغيرات في الحسابات
- عرض المتغيرات

### الأمثلة العملية

الإعلان عن المتغيرات:

```javascript
let age = 16;
let score = 100;

console.log(age);
console.log(score);
```

تغيير قيم المتغيرات:

```javascript
let number = 10;

number = 20;

console.log(number);
```

استخدام المتغيرات في الحسابات:

```javascript
let x = 10;
let y = 5;

console.log(x + y);
```
